Porthole

Your AI coding agent, looking through one tab at a time.

Porthole shows your agent only the tabs you explicitly share, and only for reading until you say otherwise. Nothing is sent anywhere — the connection is to a server running on your own machine, on localhost.

Three steps

  1. Install the bridge

    In a terminal:

    npx claude-chrome-bridge setup

    Registers with Claude Code for every project and prints your pairing token.

  2. Pair this extension

    Paste the token that command printed:

    You can also do this any time from the Porthole popup.

  3. Share a tab

    Open the page you want help with, click the Porthole icon in your toolbar, and choose Share this tab. Then ask your agent to read it.

    Chrome will show its own “Porthole is debugging this browser” banner on shared tabs. That banner is intentional — it is how you can always tell what is being watched. Closing it stops sharing.

What it can and cannot do

Can

  • Read tabs you share — text, structure, screenshots
  • Report console errors and failed network requests
  • Click, type and navigate — only after you enable Allow control for that tab

Cannot

  • See any tab you have not shared, or list them
  • Read password fields — their values are never captured
  • Keep access after you close the tab, change site, or hit Stop all sharing
  • Send anything off your machine — there is no server but your own
